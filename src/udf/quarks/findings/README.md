## Exclusion overlay rule
`q-findings-dot-2-coloring-grey.svg` is used in `.q-findings-overlay` with:
- `mix-blend-mode: exclusion`
- full-page fixed positioning
- pointer events disabled

See `q-findings.css` for utility classes.
