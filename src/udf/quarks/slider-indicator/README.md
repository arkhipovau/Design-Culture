# Q_SliderIndicator

Quark states for slider pagination indicator.

## Files
- `q-slider-indicator-default.svg` (2x2, dark grey)
- `q-slider-indicator-hover.svg` (2x2, black)
- `q-slider-indicator-active.svg` (80x2, black)

## Suggested usage
- Default: inactive dots
- Hover: inactive dot on hover/focus
- Active: current slide marker
