# A_Slider

Progress atom built from small quark-like dots and one active line.

## Markup
```html
<div class="a-slider" data-auto data-total="9" data-active="4" aria-label="Слайдер"></div>
```

- `data-total`: number of steps
- `data-active`: active step index (0-based)

Use `.a-slider--compact` for the `M_SliderControllers` variant.
