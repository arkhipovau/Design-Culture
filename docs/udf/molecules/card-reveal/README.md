# M_Card_reveal

Marks `.m-journal-card` and `.m-gallery-card` with `.is-loaded` after their preview image decodes. Works with `udf/runtime/micro-animations.css` fade-in rules.

```html
<script defer src="{{ASSET_ROOT}}udf/molecules/card-reveal/m-card-reveal.js"></script>
```

Used on `index.html`, `journal.html`, `gallery.html`.
