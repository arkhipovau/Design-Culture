# O_InterviewBody

Main Q&A column: one or more `m-interview-section` blocks, optional `m-photo-slot` / `m-photo-row` between sections.

## Markup

```html
<div class="o-interview-body a-section">
  <div class="m-interview-section">
    <div class="m-interview-section__body">
      <div class="m-qa-row m-qa-row--question">…</div>
      <div class="m-qa-row">…</div>
    </div>
    <blockquote class="m-quote-block">…</blockquote>
  </div>
  <figure class="m-photo-slot">…</figure>
</div>
```

## Dependencies

- `m-interview-section`, `m-qa-row`, `m-quote-block`, `m-photo-slot`
