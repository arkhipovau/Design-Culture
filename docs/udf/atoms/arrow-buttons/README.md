# A_ArrowButtons

Atom for 40x40 circular arrow buttons.

## Variants
- `.a-arrow-button--corner`
- `.a-arrow-button--left`
- `.a-arrow-button--right`
- `.a-arrow-button--up`

## States
- Default: base colors per variant
- Hover: medium grey (`#C8C8C8`) for corner/left/right, dark grey (`#818181`) for up
- Pressed: black bg + white icon for corner/left/right, inverted for up
- Unable: set `disabled` or `.is-disabled` (opacity `0.4`)
